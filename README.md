# Eclyria: Riftfall

**An experimental fantasy RPG experience for Minecraft.**

Eclyria: Riftfall is a custom Minecraft RPG project developed by **Darknet_Dweller**, under **NullWalkers**. The project aims to bring MMO-inspired progression, custom equipment, magical abilities, unique resources, and custom-generated worlds into Minecraft.

## Overview

Eclyria is designed around an open-world RPG experience featuring:

- Custom RPG classes and progression.
- Unique weapons, equipment, and magical items.
- Mana and ability systems.
- Custom resources and ore families.
- Themed Rift dimensions.
- Custom terrain generation.
- Interactive RPG menus.
- Player collections and crafting.
- SQLite-based player profiles.
- Environmental ambience.

## RPG Classes

The project currently defines four classes:

| Class | Identity |
|---|---|
| Vanguard | Frontline combat |
| Arcanist | Arcane abilities |
| Ranger | Ranged combat |
| Luminary | Magical support |

## Rift Worlds

Three themed dimensions are planned and represented in the preview source:

- **Verdant Reach** — Nature-inspired environment.
- **Ember** — A hostile volcanic environment.
- **Void** — A mysterious dimension with unique terrain.

Each world is intended to have its own resources, atmosphere, and exploration opportunities.
